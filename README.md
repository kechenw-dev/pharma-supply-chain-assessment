# SCCM 供应链健康评估

上海恒越禾生物医药有限公司已认证微信小程序的原生小程序工程。此仓库仅存源码，不保存真实客户答卷、联系方式、银行账户或平台密钥。

## 当前实现

- 5 分钟免费自评：4 类业务、5 类岗位、14 道核心场景题和 1 道岗位适配题。
- 可从四个常见工作问题切入，相关题目优先显示；本地保存答题进度，完整自评仍覆盖七维。
- 七维结果与透明机制计数；不生成无来源的百分制或行业排名。
- 联系信息登记、回访线索和正式诊断申请。
- 远程专题／现场全链路项目、报价状态、人工核实对公到账、开票状态。
- 正式合作后的 16 项深入访谈记录，逐题保存资料来源；库存金额题另记期间和币种。
- 人工编辑与预览中文 PDF；购买方指定接收人用邀请码及手机号绑定微信身份，批准后在小程序查看。
- 管理员可打开已批准报告，经核对后人工通过微信或企业微信发送，并记录渠道、接收人、授权依据及版本。
- 管理员身份由云函数环境变量 `ADMIN_OPENIDS` 指定，客户端不可自行提权。

微信支付因尚无商户号暂未接入；页面不收取小程序内款项。完整的上线步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)，数字规则见 [RULES.md](RULES.md)。

## 本地检查

Node.js 20+：

```powershell
node scripts/fetch-font.js
node --test tests\*.test.js
node --check cloudfunctions\assessmentApi\index.js
```

在微信开发者工具中打开本目录，确认 AppID；配置 `miniprogram/config.js` 中的真实云环境 ID。部署云函数前先运行字体下载脚本并核验通过，再安装并上传 `assessmentApi` 云函数依赖。字体文件不提交到源码仓库。

## 数据与边界

客户数据仅由云函数访问；上线前必须将六个数据库集合和报告存储设为客户端不可直接读写。免费结果来自受测者自评，不能作为 GMP 合规认定。报告仅在人工核实、审核、批准后交付。小程序内隐藏下载菜单不能阻止截图或已授权接收人传播文件；敏感资料应按合同与企业内部流程管理。
